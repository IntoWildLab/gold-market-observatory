# 黄金市场观察站 · Gold Market Observatory

轻量级黄金研究 Dashboard 原型（Prototype v1）。目标不是"大而全"，而是把 **黄金价格 / 美元指数 / 美国实际利率 / 美债收益率 / 黄金ETF资金流 / 央行购金** 这几类真实数据接起来，帮助你快速回答：

> 黄金最近涨了还是跌了？当前主要受哪些因素影响？美元、实际利率、资金流、央行购金是否形成共振？短期与中长期环境分别如何？

**原则：真实数据 > 页面漂亮；解释清楚 > 指标堆砌；能运行 > 架构炫技。**

---

## 一、快速开始

```bash
# 1. 安装依赖 (Node 18.18+, 建议 Node 20/22/24)
npm install

# 2. (可选) 配置 FRED API Key —— 免费, 用于更稳定地获取 FRED 系列
#    注册: https://fred.stlouisfed.org/docs/api/api_key.html
cp .env.example .env    # 然后填入 FRED_API_KEY

# 3. 抓取/更新真实数据快照 (会写入 data/series/*.json)
npm run data:fetch

# 4. 启动开发服务器
npm run dev
# 打开 http://localhost:3000
```

生产模式: `npm run build && npm run start`。

> 首次运行 `data:fetch` 需要联网。所有数据均为**真实数据**，抓取后以快照形式保存在 `data/series/` 下，页面直接读取快照，因此断网也能查看（数据停留在最近一次抓取时间）。

### 中国黄金层说明（本轮新增）

- **Au99.99** 是国内人民币计价黄金的重要价格参考，**不是"国内版 XAU/USD"**——两者交易市场、报价单位（元/克 vs 美元/盎司）和市场结构不同，页面已明确标注。
- **国际黄金 → 人民币汇率 → 国内黄金 → 国内ETF** 的映射关系：人民币计价黄金同时受国际金价与 USD/CNY 影响（汇率解释仅作为观察框架，不写成严格等式、不构成因果断言）。
- **人民币理论折算参考值** = XAU/USD × USD/CNY ÷ 31.1035（元/克），仅作研究参考（页面明确标注"理论折算参考值"，非"合理价格"）。采用**日度对齐**（取最近共同交易日），因三个市场交易时段/时区/节假日不同，**不做伪实时价差**；并展示国内溢价/折价（% 与元/克）。
- **518880 份额为季度披露频率**（期末总份额/期间净申购），不显示为日度；用于观察国内投资者是否持续申购，不代表推荐。**支付宝等销售平台不作为数据源或研究对象**。
- 国内外投资资金**分别观察**：全球 ETF + GLD 代表国际资金行为（资金层），518880 代表国内资金行为（中国黄金面板），不混为一谈。

### FRED 接入方式（重要）

- 配置 `FRED_API_KEY`（免费）→ 使用官方 API，稳定。
- 未配置 → 回退 `fredgraph.csv`（免 Key，但有反爬限流：连发 4~5 次会短暂封禁，冷却后恢复；代码内置 12s 最小间隔 + 退避重试）。
- 抓取失败时保留上次快照并在页面标注，不会伪造数据。

### 代理指标说明（诚实标注）

- **美元指数**：FRED 不提供 ICE DXY，本站使用美联储官方**广义美元指数 DTWEXBGS**（1973 年 3 月 = 100，权重与 DXY 不同）作为代理，页面明确标注"代理指标"。若你在 `.env` 配置了 `FRED_API_KEY`，仍无法直接获得 ICE DXY（该数据不免费公开）。
- **黄金历史价**：使用 LBMA Gold Price（伦敦定盘，官方基准价）作为现货黄金历史序列；实时盘中价另用 WGC 现货报价显示。

## 六、黄金驱动面板 & 市场温度（四维度透明规则，v2 结构）

**设计原则（v2 重构）**：
- **取消"每条规则 +1 → 8/8 满分"的等权累加**，改为四个维度的方向判定；
- **降低相关指标重复计分**：10Y 名义收益率、GLD 持仓降为"辅助确认"（不独立投票）；
- **黄金自身趋势单独展示**，不作为驱动因素投票（避免"因为黄金涨所以环境强"的循环解释）；
- 所有判定来自 `lib/scoring/rules.ts` 中的明确规则，页面可逐条展开查看依据。

### 四维度判定规则

| 维度 | 观察指标 | 时间尺度 | 判定规则 |
|---|---|---|---|
| **宏观环境** | 美元(代理)、10Y实际利率（核心）；10Y名义收益率（辅助确认） | 近5个交易日 | 美元↓且实际利率↓ → 偏利多；方向相反 → 中性；均↑ → 偏利空；数据不足 → 中性。名义收益率方向与实际利率一致时标注"确认"，背离时标注"背离"（不改变判定） |
| **资金环境** | 全球黄金ETF近4周资金流（核心）；GLD近20日持仓（辅助确认） | 近4周 / 近20交易日 | 近4周合计>0 → 偏流入；<0 → 偏流出；=0/不足 → 中性。GLD 方向与全球ETF一致时标注"确认" |
| **长期结构** | 全球央行最近季度净购买、中国央行最近季度变化 | 季度（最近公布） | 两票均>0 → 偏支持；一票 → 中性；零票 → 偏弱。仅用于中长期需求观察，不解释当日行情 |
| **黄金趋势** | 黄金价格近20个有效观测收益率 | 近20个交易日 | ≥+1.5% → 上行；≤−1.5% → 下行；其余 → 震荡。**单独展示，不参与驱动判定** |

### 综合状态（由规则计算，非 AI 判断）

三个驱动维度（宏观/资金/长期结构）方向计数：**有利维度数 − 不利维度数 ≥ 2 → 🟢 偏强；= 1 → 🟡 中性；≤ 0 → 🔴 偏弱**（中性维度计 0）。

综合描述由模板生成，例如：
- 三个维度均有利 → "当前宏观、资金与长期结构均对黄金相对友好，黄金自身近20日趋势上行。"
- 趋势下行但驱动有利 → 追加"注意: 黄金自身趋势仍在下行，短期价格动能与宏观环境存在背离"。

页面明确提示：该评估仅用于观察驱动因素方向与共振情况，**不构成投资建议**。

## 九、常见问题

**Q1: 页面显示"存在 N 个系列缺失"？**
说明 `data:fetch` 从未成功抓到这些系列（通常是 FRED 限流或网络问题）。运行 `npm run data:fetch` 重试；配置 `FRED_API_KEY` 可大幅提高 FRED 系列成功率。

**Q2: 数据多久刷新一次？**
快照不会自动刷新。需要每天看最新数据时，运行 `npm run data:fetch`（可加 cron）。页面显示"最近数据刷新时间"即快照抓取时间，绝不把快照时间伪装成实时。

**Q3: 为什么中国央行储备是季度而不是月度？**
人民银行按月公布官方储备资产，但稳定、可机读的月度接口（WGC/IMF 月度文件）在该环境下被反爬限制（403）。为保证"真实数据优先"，v1 采用 WGC/IMF IFS **季度**确认值并在页面明确标注频率；月度明细可访问人民银行官网。**绝不把季度数据显示成月度。**

**Q4: 为什么美元指数带"代理"标签？**
FRED 不提供 ICE DXY，使用的是美联储官方广义美元指数（DTWEXBGS），权重与 DXY 不同，页面已显著标注。

**Q5: 评分是 AI 算的吗？**
不是。评分完全由 `lib/scoring/rules.ts` 中 8 条可读规则计算，页面可逐条展开查看依据。

## 十一、已知限制（v1）

1. **美元指数为代理指标**（美联储广义美元指数），非 ICE DXY。
2. **中国央行储备为季度口径**（WGC/IMF IFS），月度明细需访问人民银行官网。
3. **FRED 免 Key 方式有限流**，配置 FRED_API_KEY 后更稳定。
4. **ETF 数据为周频**（WGC），与日频指标不直接比较；页面已按时间尺度分层展示。
5. 黄金历史使用 **LBMA 定盘价**（官方基准价），非盘中逐笔价格；实时价单独显示。
6. 无实时盘中图表刷新（快照制），适合每日/定时观察。
7. 央行购金为**季度**数据，不可用于解释单日涨跌（页面已明确提示）。
8. 全球央行购金为 WGC GDT 口径（净购买），与部分央行"增持-减持"公告口径可能有细微差异。
9. **人民币理论折算参考价**为日度对齐（LBMA 定盘 / H.10 / SGE 收盘，交易时段不同，中国节假日 SGE 休市），仅作研究参考，页面已明确标注，不做伪实时价差。
10. **国内 ETF 份额为季度披露**（基金公司定期报告），不是日度；当日成交额/成交量为交易所行情快照。
11. **国内行情接口为公开金融数据平台**（腾讯/新浪/东方财富），聚合自交易所与基金公司披露，非交易所官方 API；若接口不可用，`data:fetch` 会保留旧快照并在页面标注。
